CampusFlow Next

CampusFlow Next is an improved version of our existing CampusFlow Python command-line application. It helps campus support staff manage maintenance and technical issues, track their progress, and generate useful reports.

## Project Goals

The goal is to make the existing application more reliable, easier to use, and easier to maintain without rebuilding it from scratch.

## Features

CampusFlow Next builds on the original features and aims to provide:

- Ticket Management:Create tickets, assign staff, and manage ticket status.
- Validation: Reject invalid inputs and prevent invalid ticket operations.
- Follow-up Notes: Add and view notes for tickets.
- Search and Filtering: Find tickets using search terms and multiple filters.
- Reports:View ticket statistics by status, priority, and category.
- JSON Persistence: Save and load tickets and notes.
- Testing: Verify existing and new functionality using automated tests.

## Technologies

- Python
- JSON for data persistence
- `unittest` for automated testing
- Git and GitHub for version control and collaboration
